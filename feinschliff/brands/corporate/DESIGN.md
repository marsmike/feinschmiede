## Overview

Corporate is a brand-pack port of a free Microsoft PowerPoint template from the
**Microsoft PowerPoint Gallery**. The master deck is hosted off-repo and
resolved at render time via `master.pptx.ref`.

## Attribution

The source template is © Microsoft, distributed for free reuse through the
Microsoft PowerPoint Gallery (<https://create.microsoft.com/en-us/templates>). This pack references the unmodified
master; feinschliff only overlays color themes at render time.
